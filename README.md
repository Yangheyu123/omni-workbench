> 面向 AI 漫剧创作者的「单镜创作台」:**提示词 + @素材引用 → 多参考生视频 → 版本管理 → 采用成片**,并配齐模型选择与计费预授权/结算的完整闭环。

## 1. 解决的问题与目标用户

**目标用户**:做 AI 漫剧/短剧的小团队创作者(编导 1-2 人 + 出片)。

**核心问题**:剧本到成片之间,单镜视频生成是最高频、最贵、返工最多的一环。现有工具要么是纯文生视频(素材无法复用、人物不一致),要么是重流程平台(改一个镜头要走完全流程)。创作者真正需要的是**围绕"一个镜头"组织工作**:这一镜用哪些角色/场景素材、提示词怎么写、哪个版本好、花多少钱。

**本切片**:从剧本产出的分镜出发,提供单镜工作台——素材以 `@名称` 引用进提示词、按模型能力路由(参考图/动效/音频)、生成走"报价 → 预授权冻结 → 结算"的透明计费、版本可对比可回切。**视频感染力最终由镜头语言决定,这个切片把"镜头级"的掌控权交给创作者。**

## 2. 关键选择

- **复用生产级组件而非重写 UI**:工作台组件(FreeCreate 及其依赖)与本人 0→1 开发的漫剧平台强相关。这既证明了组件与数据层的解耦,也让演示行为与真实产品同构。
- **mock 层做在请求层而非组件层**:唯一被替换的文件是 `src/utils/request.js`——与真实 axios 封装同形(方法、响应解包、错误约定一致)。组件零改动即切换数据源,这是"同形替换"的直接验证。
- **计费做真闭环而非数字游戏**:提交生成即按报价冻结余额,完成后结算扣费并写流水(失败路径为释放),余额徽章实时反映。让"每一镜花多少钱"成为创作决策的一部分。
- **生成任务做状态机**:排队 → 生成画面 → 合成 → 完成,前端轮询与生产一致(生产对接火山 Seedance/可灵;演示 3 秒模拟完成)。

## 3. AI 如何参与开发

全程 AI 结对完成,本人负责判断、拆解与验收:

- **依赖盘点**:让 AI 静态分析工作台组件的 import 闭包与 API 调用面(约 25 个接口),得出"只需替换请求层一个文件"的结论——这个判断决定了整个方案的成本;
- **契约对齐**:AI 对照后端服务源码推导 `/video-model-capabilities` 等接口的返回形状,浏览器实测发现 capability 结构不匹配(`id` vs `model + limits 嵌套`)后由 AI 定位到消费代码修正 fixtures;
- **端到端验证**:AI 驱动浏览器走完"插入 @素材 → 生成 → 轮询 → 出片 → 余额变动"全路径,替代手工回归;发现 `@苏晚` 引用失效(别名集合不含短名)等问题并即时修复;
- **边界控制**:AI 输出的兜底策略(未命中接口静默成功)被本人驳回,改为显式警告——演示不能掩盖未实现。

## 4. 完成边界(如实说明)

| 能力 | 状态 |
|---|---|
| 工作台 UI/交互/校验/状态机/版本管理 | **真实**(与生产同码) |
| 模型选择、生成参数联动、报价预估 | **真实逻辑 + 演示数据** |
| 计费:报价→冻结→结算/释放→流水 | **真实流程 + 模拟金额** |
| 生成任务 | **模拟**:3 秒完成并挂 CC0 演示视频,不调用真实模型 |
| 项目数据(分镜/素材/账户) | 静态 fixtures,刷新重置 |
| 登录/权限/服务端持久化 | 不适用(纯前端演示) |
| 未完成 | 真实模型接入、生产媒体归档闭环、计费对账闭环、多镜头连播 |

**下一步优先级**:
1. **生产媒体归档闭环**——生成产物落 OSS 归档、断点续传与本地清理,保证成片可追溯、可恢复;
2. **计费对账闭环**——预授权/结算/释放与供应商账单的对账、异常损失审计,让每一笔扣费可核验;
3. **接入真实 API**——对接火山 Seedance 2.0 多参考生视频等真实模型,组件与请求层已就绪,只需把 mock 换回真实 base URL 与鉴权。

## 5. 投入时间

- 本切片(抽取 + mock 数据层 + 计费闭环 + 验证):**约 3小时**;
- 背景说明:工作台mock组件来自本人此前实习 0→1 开发的漫剧平台。

## 6. 运行

```bash
# 方式一:本地
npm install
npm run dev            # http://localhost:3020

# 方式二:Docker
docker compose up -d   # http://<host>:8020

# 方式三:直接拉取 Docker Hub 镜像(免构建,推荐发给别人)
docker run -d --name omni-workbench -p 8020:80 yangheyu0803/omni-workbench:latest
```

纯前端,无后端/密钥依赖。构建:`npm run build`。

## 7. 体验路径(约 2 分钟)

1. 打开首页,左侧为演示项目「00:07 的电台」5 个分镜(镜头 1、2 已有成片)
2. 提示词框输入 `@苏晚` 或 `@画室`(素材以芯片插入;也可点素材卡"插入此处")
3. 右侧调整生成参数(模型/时长/分辨率),观察报价联动
4. 点「生成当前镜头」→ 余额出现**冻结** → 约 3 秒完成 → **结算扣费**,新版本自动成为当前成片
5. 右上角余额徽章进入**账户中心**查看交易流水;版本卡可「设为当前成片」回切

## 目录速览

```
├── docker-compose.yml / Dockerfile / nginx.conf   # 一键部署
└── src/
    ├── mock/               # fixtures(演示项目)+ handlers(接口路由/内存store/计费状态机)
    ├── utils/request.js    # 唯一被替换的文件:与生产 axios 封装同形的 mock 层
    ├── views/FreeCreate.vue# 工作台(生产组件原样拷贝)
    └── views/Account.vue   # 账户中心(余额 + 交易流水)
```
